reHyve - Website (June 4 build)
===============================
"Refresh. Recover. Rebuild."

reHyve 40g Energy Gel - a fast-absorbing, dual-carb endurance fuel
built for runners, cyclists and endurance athletes.

WHAT'S INSIDE
  index.html    The website (open this)
  styles.css    Styling and animations
  script.js     Interactivity
  assets/       Logos, favicons, wave pattern and icons

HOW TO VIEW IT
  Easiest:  Double-click index.html to open it in your browser.

  Best (recommended, loads everything perfectly):
    1. Make sure Python is installed.
    2. Open this folder in a terminal.
    3. Run:  python -m http.server 8000
    4. Open your browser to:  http://localhost:8000

NOTES
  - Fonts (Figtree + Source Serif 4) load from Google Fonts, so an internet
    connection is needed for the exact typography. All logos, icons and the
    wave pattern are bundled and work offline.
  - Fully responsive - desktop, tablet and mobile.
  - The "Join the hive" buttons scroll to the email signup section
    (lead capture - no payment processing is wired up).
